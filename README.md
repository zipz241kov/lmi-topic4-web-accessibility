# \## Структура репозиторію

# \* `main.html` — головна сторінка інтернет-магазину ACME Fashion House після покращення доступності\[cite: 35].

# \* `form.html` — сторінка форми замовлення / підписки після рефакторингу елементів керування та групування полів\[cite: 35].

# \* `README.md` — опис проєкту, виконаних змін та результатів перевірки.

# 

# \## Основні виконані покращення

# 

# \### Сторінка `main.html`

# 1\. \*\*Заголовок сторінки (`<title>`)\*\* — замінено шаблонний заголовок на змістовний (`Home | ACME Fashion House — Seasonal Collection \& Store`)\[cite: 35].

# 2\. \*\*Мова документа (`lang`)\*\* — додано атрибут `lang="en-GB"` для коректного озвучення англомовного контенту екранними читачами\[cite: 35].

# 3\. \*\*Посилання пропуску навігації (Skip Link)\*\* — додано посилання `Skip to main content` із переходом до `#main-content`\[cite: 35].

# 4\. \*\*Ієрархія заголовків (`<h1>`–`<h3>`)\*\* — замінено стилізовані `<div>` на семантичні заголовки без пропусків рівнів\[cite: 35].

# 5\. \*\*Елементи-орієнтири (Landmarks)\*\* — використано `<header>`, `<nav>`, `<main>`, `<section>` та `<footer>`\[cite: 35].

# 6\. \*\*Порядок табуляції (`tabindex`)\*\* — прибрано штучні позитивні значення `tabindex`, що порушували природну послідовність фокусу\[cite: 35].

# 7\. \*\*Контрастність кольорів\*\* — підвищено контрастність тексту та елементів інтерфейсу до рівня не менше `4.5:1` (WCAG AA)\[cite: 35].

# 8\. \*\*Альтернативний текст зображень (`alt`)\*\* — додано змістовні описи для інформативних зображень та `alt=""` / `role="presentation"` для декоративних\[cite: 35].

# 9\. \*\*Семантичні елементи\*\* — застосовано `<article>`, `<blockquote>` та `<cite>` для карток товарів і відгуків\[cite: 35].

# 10\. \*\*Зрозумілі посилання та `aria-label`\*\* — додано інформативні підписи для посилань-іконок і кнопок\[cite: 35].

# 11\. \*\*Групування посилань (`<ul>` / `<li>`)\*\* — оформлено списки навігаційних посилань у структуровані списки\[cite: 35].

# 

# \### Форма `form.html`

# 1\. \*\*Мітки полів (`<label for="...">`)\*\* — явно пов'язано кожне поле введення з відповідною міткою\[cite: 35].

# 2\. \*\*Обов'язкові поля (`required`, `aria-required`)\*\* — позначено обов'язкові поля програмно та візуально\[cite: 35].

# 3\. \*\*Групування елементів (`<fieldset>` та `<legend>`)\*\* — згруповано радіокнопки вибору доставки у логічний блок із заголовком\[cite: 35].

# 

# \## Перевірка доступності

# \* \*\*Автоматизовані інструменти:\*\* axe DevTools та WAVE Accessibility Extension (0 помилок після рефакторингу на `main.html` і `form.html`)\[cite: 35].

# \* \*\*Ручна перевірка:\*\* навігація клавіатурою (`Tab`, `Shift+Tab`, `Enter`, `Space`, робота `Skip Link`) та тестування екранним читачем \*\*NVDA\*\*\[cite: 35].
